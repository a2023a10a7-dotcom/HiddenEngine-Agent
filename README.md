# HiddenEngine-Agent

AI-powered production agent for The Hidden Engine YouTube channel.

## Mission
Research, plan, write, produce, and prepare YouTube videos.

## Workflow
1. Discover video topics.
2. Research competitors.
3. Verify facts and sources.
4. Write English scripts.
5. Generate voiceovers.
6. Collect visuals.
7. Render MP4 videos.
8. Prepare titles, descriptions, and thumbnails.

## Safety
- Never publish without owner approval.
- Never delete channel content.
- Never expose API keys or credentials.
